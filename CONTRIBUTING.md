## 📌 What krita-desktop Does

krita-desktop is described as a local Windows and macOS helper for Krita data paths, config and export caches, and export folders. In everyday use, that means it helps with the housekeeping that sits around your artwork:

- Finding common Krita data folders on your computer.
- Showing where Krita configuration files are stored.
- Helping you review or manage export cache locations.
- Opening export folders so you can find finished images more easily.
- Keeping helper actions local to your computer.
- Reducing the need to hunt through hidden folders by hand.

The utility is especially useful if you export artwork often, change Krita settings, or want a clearer view of where Krita keeps its working files. It is intended for normal desktop use on Windows, with the repository description also noting macOS helper use. The download and run steps in this README focus on Windows because that is the main end-user path.

## 🚀 Getting Started

Before you begin, make sure Krita is already installed and that you have used it at least once. krita-desktop is a helper for Krita folders and caches, so it works best when Krita has already created its normal local files.

You do not need to install extra developer tools. You do not need to open a terminal. You do not need to edit configuration files by hand. The goal is to download the helper, open it, and let it help you reach the Krita paths and folders you need.

## 🧭 First-Time Setup

The first time you open krita-desktop, take a moment to look through the main screen before changing anything. A good first-time routine is:

1. Open the helper from the downloaded file.
2. Let the main window load fully.
3. Look for the section that shows Krita data paths or folder locations.
4. Use the open-folder actions to confirm that the paths point to folders that exist on your computer.
5. Review the configuration and export cache areas without deleting anything.
6. Open your export folder to see where finished images are normally saved.

If Krita is installed in a standard way, the helper should be able to show useful local locations. If you have moved folders or use a portable-style Krita setup, review the paths carefully before making changes. The helper is meant to make these locations easier to reach, not to force you into a complex setup.

You can close the helper at any time. Nothing in the normal review process requires you to keep it running in the background.

## 🗂️ Everyday Uses

krita-desktop fits into simple daily routines:

- Before backing up your work, open the helper to find the Krita data and configuration folders.
- After exporting artwork, use the helper to open the export folder instead of searching through File Explorer.
- When Krita feels cluttered with old export files, review the export cache area and decide what to clean up.
- When you want to confirm where Krita stores settings, use the configuration section as a quick reference.
- When you move to a new computer, use the helper to understand which folders matter before copying your Krita-related files.

The helper is local. It is designed around folders and files on your own computer, not around uploading your artwork or settings to an online service. That makes it a practical tool for users who prefer to keep their Krita workspace organized on their own machine.

## 🧹 Export Cache and Folder Help

Export caches and export folders can become confusing because they are often outside the main Krita project folder. krita-desktop gives you a clearer way to reach them.

An export cache is a temporary or supporting storage area used during export work. You normally do not need to open it by hand. If you want to review disk usage or clean up after a large export session, the helper can point you to the right place. Treat cache cleanup carefully: close Krita first, review what is present, and remove only files you recognize as temporary export data.

An export folder is where finished images are saved. If you frequently export PNG, JPEG, or other image files, the helper can open that folder quickly. This is useful when you want to rename files, move finished artwork into a project folder, or attach an image to a message.

If you are not sure whether a folder is a cache or a final export location, open it and look at the file names before changing anything. Keep backups of important artwork. Do not delete a folder just because the helper can open it.

## 🔒 Local and Simple

krita-desktop is described as a local helper. That means its purpose is to work with local Windows and macOS paths, configuration, caches, and folders. It does not ask you to learn a programming language or manage a server.

For safest use, download only from the project link in this README, keep your important artwork backed up, and review folders before deleting files. Use the helper to open locations and understand your Krita setup. If a change feels risky, stop and make a backup first.

## 🛠️ Troubleshooting

If the download does not start, return to the project page and use the main download control again. Make sure your browser is not blocking the download and that you have enough free disk space.

If the downloaded file does not open, check that the download completed fully. A partial download may not open correctly. Remove the incomplete file and download it again from the same project page.

If the helper opens but a folder looks empty, confirm that Krita has been opened at least once on that computer. Some Krita folders are created only after normal use.

If you use a portable-style Krita setup or store your work in a custom location, review the paths shown by the helper before making changes. The helper can make folders easier to reach, but you should still confirm that each path matches your own setup.

If you are unsure about a configuration file, do not edit it. Open the folder, make a backup if needed, and leave the file unchanged until you know what it controls.
